# Application Overview: Automation Exercise

## 1. Application Name
Automation Exercise (https://automationexercise.com/)

## 2. Type of Application
B2C E-commerce web application (online clothing store)

## 3. Purpose
Let user browse products and buy clothes without going to physical store.

## 4. Target users: 
- Guest user ( can browse products and add to cart but no checkout allowed)
- Registered user( can browse products and add to cart but checkout allowed). 
- No admin role is visible or accessible from public site.

## 5. Main features: 
Account signup, account login, search products, filter products by brand and category, view product details, add products to cart, checkout, remove items from cart ,place order and payment, download invoice, delete account , write reviews ,  contact us form, newsletter subscription, account logout.
## 6. The main user journey:
- Returning user:  Login-> Browse -> Other flows-> View product -> Add to cart-> Checkout->Place order-> Pay and confirm order->Download invoice-> Logout.
- New user:  Signup-> Browse ->Other flows->View product -> Add to cart-> Checkout->Place order-> Pay and confirm order-> Download invoice-> Logout.

## 7. Questions
### Clarifying Questions
- How will we decide which items are gonna listed as recommended items?
- What if the product is out of stock? 
- Is there a limit of product items a customer can purchase? 
- What are the rules for password(maximum/ minimum length, required special characters)? 
- What should happen if the customer log in with an email that is already registered?
- Is there a chance customers can reset their password if customers forget their old passwords?
### Suggestions
- Customers should be able to add their card info in their profile instead of filling the card info every time users try to checkout.
- Customers should be able to get access to their placed orders.
